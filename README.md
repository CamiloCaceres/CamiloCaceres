### I build software companies, and the agents that help run them.

Most of my day isn't typing code. I write charters, delegate, review and decide, and a team of AI agents does the rest across every product I work on. Getting that to work for real (permissions, memory, accountability, nothing reaching prod without a human) is what I find most interesting right now.
